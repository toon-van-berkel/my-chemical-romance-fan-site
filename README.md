# 🖤 My Chemical Romance Fan Site

### An unofficial frontend project inspired by My Chemical Romance

A fan-made website exploring **responsive frontend development, visual identity and expressive web design** through the aesthetic of My Chemical Romance.

[View the website →](https://toon-van-berkel.github.io/PP-MCR/)

</div>

---

## 🖤 About the project

This project started as a frontend design exercise and gradually grew into a complete multi-page fan website inspired by **My Chemical Romance**.

Rather than creating a generic practice website, I wanted to work with a strong visual identity.

The dark, alternative aesthetic of MCR gave me an opportunity to experiment with typography, imagery, contrast, layered layouts and expressive interface design while improving my frontend development skills.

---

## 🌐 Website sections

The project contains several dedicated pages:

- **Home**
- **Band**
- **Music**
- **Gallery**
- **News**
- **Events**
- **Merch**

Together they form a small fan-oriented website rather than a single frontend exercise page.

---

## 🎨 Design goals

The project focused on translating an existing visual identity into a functional website.

During development I experimented with:

- Dark and high-contrast interfaces
- Responsive layouts
- Typography
- Image-heavy page design
- Navigation systems
- Hover and interaction effects
- Reusable visual patterns
- Multi-page website structure
- Combining Bootstrap with custom styling

The goal was to avoid making the website feel like a generic template and instead give it a visual identity that matched the subject.
